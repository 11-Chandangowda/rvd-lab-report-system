# 🐾 RVD Lab Report System

A web-based diagnostic report retrieval system for Rohana Veterinary Diagnostic Lab.

---

## 🚀 Features

- 🔍 Fetch reports using Phone Number + Lab Number
- 📄 Instant PDF download
- 📊 Google Sheets used as lightweight database
- ☁️ Google Drive used for report storage
- ⚡ Fast and simple UI

---

## 🧠 Architecture

User → Website → Backend API → Google Sheets → Google Drive → Report

---

## 🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- Database: Google Sheets
- Storage: Google Drive

---

## ⚠️ Note

This is a prototype/demo version.  
Production deployment will include:
- Secure API handling
- Cloud hosting
- Company-owned credentials
